## 1. สรุปผู้บริหาร

- **สถานะปัจจุบัน:** โครงหลักสูตรครบ 11 โมดูล / 36 sections และ 11 แล็บ (40 Exercise) แต่**จบมาตรฐานการสอนจริงแค่ Module 1 (5/5 sections)** — ที่เหลือ 31/36 เป็น outline (สั้นสุด 20 บรรทัด); ส่วนเสริมเชิงระบบยังว่าง: ไม่มี glossary, ไม่มีบรรทัด "ต้องรู้มาก่อน" ใน sections, ไม่มี version guard ใน .sql ทั้ง 69 ไฟล์, แล็บไม่มีเกณฑ์ `**Expected:**` ที่เป็นรูปแบบเดียวกัน
- **สไลด์ปัจจุบัน:** เด็ค Trainocate 4Days มี 78 สไลด์แต่ทั้งเด็คใช้ layout `DEFAULT` และไม่มี speaker notes แม้แต่ใบเดียว — ยังเป็น skeleton ไม่ใช่เด็คสอน; template `Trainocate_SQLPerfTuning_Template.potx` (8 layouts, 16:9, ฟอนต์ Leelawadee UI) พร้อมใช้
- **เป้าหมาย:** "หลักสูตรสมบูรณ์" = เนื้อหา 36/36 sections + 11 แล็บผ่านการรันจริงบน SQL Server 2025 (17.x) + quiz bank ครบ; "สไลด์สมบูรณ์" = 12 เด็ค / 196 สไลด์ บน template พร้อม notes 100% — ทั้งหมดมี **Definition of Done ที่ตรวจได้ด้วยคำสั่ง** ไม่ใช่ตรวจบนกระดาษ
- **ทางที่ทีมเลือก:** ทำงานสองสายขนาน — สาย **Blocking** (glossary → Module 0 ฉบับขั้นต่ำ → heading เสีย → เกณฑ์แล็บ → version guard → แก้สัญญาเท็จใน Guide) ต้องจบก่อนสไลด์เนื้อหา; สายเนื้อหาเดินตาม dependency **M5 → M9 → M11** (M2/M8 ทำขนานได้); สายสไลด์เริ่มทันทีด้วย **เด็คนำร่อง M1 + 44 สไลด์โครง** (ไม่นับเป็นเด็คจบ)
- **จุดปิดคอร์ส:** ประกาศ "จบหลักสูตร" ได้ก็ต่อเมื่อมีการรันแล็บจริงบน 17.x และ**ผู้เรียนฐาน Admin ทดสอบจริง 3 แล็บเต็มสาย (M1 + M5 + M9)**: เดิน setup/Module 0 ฉบับขั้นต่ำ → อ่านโมดูล → รันแล็บโดยไม่ต้องค้นนอก repo พร้อมบันทึกเวลาจริงที่ใช้ — M5/M9 ถูกเลือกเพราะเป็นโมดูลแรกของสายเนื้อหาและยากที่สุดสำหรับผู้เรียน (lock → XE, ฟีเจอร์ 2025-only) — เกณฑ์ที่วัด "ผู้เรียนถึงเป้าหมาย" ไม่ใช่แค่โครงสร้างไฟล์
- **DoD สองชั้น:** ชั้นโครงสร้าง (grep ตรวจได้ทุกข้อ) ต้องคู่กับชั้นคุณภาพผู้เรียน — ทุก Exercise ที่ใช้ syntax เกิน SELECT/JOIN (CTE, window function, CROSS APPLY) ต้องมีบล็อก "ต้องรู้ก่อน" อธิบาย 1–2 บรรทัด และทุกโมดูลต้องผ่านการอ่านจริงโดยผู้เรียนทดลองระดับ admin+query ก่อนถือว่าจบ
